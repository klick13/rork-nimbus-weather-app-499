## Full Description (4000 characters max)
Nimbus delivers precise, hyper-local weather with a stunning, map-first design. Track real-time conditions, animated radar, wind flow, temperature fields, and UV index maps — all in one clean, dark interface.

**What you get:**
• Real-time weather for your exact location and saved cities
• Animated weather map with radar, wind streamlines, temperature bands, and UV index
• Hourly and 7-day forecasts with precipitation chances
• Automatic weather alerts for storms, wind, heat, freeze, UV, and winter conditions
• Saved locations and GPS/network location detection
• Temperature in Fahrenheit or Celsius
• Free, keyless data sources — no API keys required

Nimbus uses free, public weather services including Open-Meteo, RainViewer, CartoDB, and OpenStreetMap so you get accurate forecasts without hidden subscriptions.

**Permissions:**
- Location: Used only to fetch weather and radar for where you are. Your location is not stored on our servers.
